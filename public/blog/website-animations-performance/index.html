Website Animations: When They Help, When They Hurt

How to use animation on a business website to delight visitors and guide attention without slowing the site, harming SEO or excluding users.

Key takeaways
  • Animation should guide attention and add delight, never block content
  • Animate transform and opacity for smooth performance
  • Load animation code after the page is usable and respect reduced-motion settings
  • Content must exist in the HTML so search engines and AI can read it

Animation is what makes a website feel alive: a headline that rises into place, a gallery that glides, a button that responds to your cursor. It's also what makes bad websites unbearable. The difference is purpose and craft.

We use a lot of motion on this site. Here's how to do it without sacrificing speed, SEO or accessibility.

What animation is good for

  • Guiding attention to what matters
  • Showing relationships: this panel came from that button
  • Giving feedback: hover, press, success
  • Telling a story as the visitor scrolls
  • Personality: a brand that feels considered and premium

When it hurts

  • It delays content ("wait for the intro to finish")
  • It distracts from the message
  • It makes pages stutter or load slowly
  • It triggers motion sickness
  • It hides content from search engines

If an animation doesn't help the visitor understand or enjoy the page, cut it.

Types worth using

Entrance reveals

Text and images that fade or slide in as they enter the viewport. Subtle and effective.

Scroll-driven effects

Parallax, pinned sections and horizontal galleries tied to scroll position. Powerful for storytelling, in moderation.

Micro-interactions

Buttons that react, links that underline, forms that confirm. Small touches that make a site feel responsive.

Page transitions

Smooth changes between pages make a multi-page site feel like one experience.

Ambient motion

Gentle background movement, such as a gradient or shader, that adds atmosphere without demanding attention.

Performance rules

Animate the cheap properties

transform and opacity are handled by the graphics processor and stay smooth. Animating width, height, margins or shadows forces the browser to recalculate layout and causes jank.

Load motion last

The page should be readable and usable before any animation library loads. Defer scripts so they don't block rendering.

Keep libraries lean

A capable animation library adds perhaps 40 to 60 KB compressed. That's fine. Stacking several libraries and plugins isn't.

Don't animate everything

Reserve motion for key moments. A page where everything moves is exhausting and slow.

Pause off-screen work

Canvas and video backgrounds should stop when they're not visible.

Test on a mid-range phone

If it stutters there, simplify.

See Core Web Vitals explained.

SEO: content first, motion second

Search engines and many AI crawlers read your HTML. Some don't run JavaScript at all.

  • All text must be in the HTML, not injected by scripts
  • Don't hide content permanently waiting for an animation that may never fire
  • Provide fallbacks if scripts fail
  • Avoid layout shift from elements that move after loading

On this site, every heading, paragraph and link exists in plain HTML. Animation only changes how it arrives.

Accessibility

  • Respect prefers-reduced-motion. People can ask their device to minimise animation; honour it.
  • No flashing more than three times a second
  • Avoid motion that hijacks scrolling unpredictably
  • Keep focus visible for keyboard users

See web accessibility basics.

Loading screens

A preloader can set the tone for a brand. Keep it brief (about a second), show it only on the first visit, and never use it to hide a slow site.

Video

Background video is a form of animation with a heavy cost.

  • Compress hard and keep it short
  • Use a poster image
  • Mute and loop
  • Skip it on slow connections

Frequently asked questions

Do animations hurt SEO?

Not when content is in the HTML, scripts are deferred and performance stays good.

Are animations worth it for a small business?

A few well-chosen ones make a site feel premium and memorable. They should never get in the way of information.

Which tools are used for web animation?

CSS for simple effects; libraries such as GSAP for complex, scroll-driven sequences; and smooth-scroll libraries for a polished feel.
